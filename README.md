# 水印工坊 · FFmpeg

一个完全在本地运行的批量视频水印工具。视频不会上传到云端。

当前版本：1.3.0（自定义水印字体）

## 功能

- 批量导入多个视频
- PNG / JPG / WebP 图片水印
- 自定义文字水印
- 自定义导入 TTF、OTF、TTC 字体
- 显示当前字体名称，并可一键恢复系统默认字体
- 动态文字水印：水平、垂直与斜向流动
- 自定义流动速度与密铺程度
- 界面内实时预览动态文字效果
- 自动适配屏幕高度，设置区支持滚轮和滚动条
- 底部导出与进度栏固定显示，不会被窗口裁切
- 九宫格位置、透明度、大小和边距
- 高质量 / 均衡 / 小体积三档导出
- 自动读取设备中已有的 FFmpeg
- 保留原始分辨率与帧率，输出兼容性较好的 H.264 MP4
- 实时显示处理进度，可中途取消
- 三步式操作流程与更直观的九宫格位置选择
- 完成后可直接打开输出文件夹

## macOS 启动方式

1. 解压整个文件夹。
2. 双击 `启动水印工具.command`。
3. 如果 macOS 首次阻止运行：右键该文件 → 打开 → 再确认打开。

也可以在终端中进入本文件夹后运行：

```bash
python3 app.py
```

## 环境要求

- Python 3（含 Tkinter）
- FFmpeg 与 FFprobe 已安装

工具会依次从系统 PATH、`/opt/homebrew/bin`、`/usr/local/bin` 中寻找 FFmpeg。

## 推荐水印素材

- 使用透明背景 PNG。
- 建议图片宽度至少 600 px，以免放大后模糊。
- 默认大小为视频宽度的 16%，透明度为 75%，通常适合广告素材角标。

## 输出规则

- 默认输出到 `Movies/Watermarked`。
- 文件名格式：`原文件名_watermarked.mp4`。
- 如已存在同名文件，会自动添加 `_2`、`_3`，不会覆盖旧文件。
